## What Remains / Next Ideas

1. **Silhouette mode for plots** — `sacred` supports `--mode silhouette` but `plot` does not;
   adding it would make harmonograph/spirograph stencil-ready.
2. **Mandala silhouette** — extend `generate_mandala` with `mode` param and fill-based rendering
   for a proper black stencil.
3. **Batch silhouette variants** — auto-generate both outline and silhouette for each daily artefact
   to maximise Cricut-ready output volume.
4. **Formula gallery page** — `forest-formula.json` and the horse formula JSON could feed a
   dedicated sub-page listing reusable Fourier formulas with previews.
5. **Metatron `mode=outline` variant** — current metatron only applies stroke colour for mode;
   an outline-background silhouette with filled inner circles would make a stronger stencil.
