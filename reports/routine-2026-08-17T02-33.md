## What Remains / Next Ideas

1. **Expand the generator library** — the scheduled script expects `metatron`, `mandala`, `harmonograph`, `spirograph`. These could be implemented in `mathart/sacred.py` and `mathart/plot.py` respectively; each would greatly diversify the daily output.
2. **Naming collision fix** — `sri-yantra --mode silhouette` and `--mode outline` both write to `sri-yantra.svg`. The CLI should suffix the mode (`sri-yantra-silhouette.svg`, `sri-yantra-outline.svg`) to preserve both renders.
3. **Forest render target** — a fractal tree / L-system renderer would complement the horse silhouette and give the Fourier trace a more organic subject.
4. **Second trace subject** — the trace step currently only targets `horse.png`; adding a second rendered subject (e.g. a new render target) would make the trace artefact feel less repetitive across runs.
5. **Silhouette mode for flower** — `sacred flower --mode silhouette` could be tested; if already supported it should be added to the routine.
