## What Remains / Next Ideas

1. **Expand the generator library** — the task spec mentions metatron, mandala, harmonograph, spirograph, and forest, none of which are implemented. Adding these would make the daily runs truly varied.
2. **Parametric variation** — the existing generators (superformula, flower) accept few parameters via CLI; exposing `--params` for things like petal count, symmetry order, or field strength would diversify output day-to-day without new generators.
3. **Color/gradient support** — all SVGs are currently monochrome; adding fill modes (gradient, palette) would prepare them for the artistic web gallery.
4. **Gallery page thumbnails** — the static `index.html` could benefit from inline PNG thumbnails alongside SVG previews for faster visual browsing.
5. **Morning vs. evening distinction** — the afternoon routine currently duplicates what the morning run produces; a split schedule (morning: sacred geometry, evening: mathematical plots + traces) would maximize daily variety.
