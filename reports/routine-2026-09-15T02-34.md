2. **Trace outline mode** — The `trace` command generates a silhouette SVG; adding an `--mode outline` option (like `sacred`) would give more design variety for Cricut stencils.

4. **Color/fill variants** — Sacred and plot SVGs are single-color; parameterising stroke color or adding gradient fills could produce richer gallery pieces.
5. **Auto-thumbnail for gallery** — The `site` command could generate PNG previews of SVGs so the web gallery shows visual thumbnails instead of raw filenames.
