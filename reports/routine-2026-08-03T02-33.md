## What Remains / Next Ideas

1. **Expand the generator library** – The scheduled task references 5 motifs that don't exist yet (`metatron`, `mandala`, `harmonograph`, `spirograph`, `forest`). Adding even one per week would significantly grow the site's visual diversity.
2. **Deduplicate outline vs silhouette filenames** – Currently both `--mode silhouette` and `--mode outline` write to the same filename (e.g. `flower.svg`), so the first is silently overwritten. The CLI should suffix the filename with the mode, or the caller should specify a distinct `--name`.
3. **Gallery front-end** – The static `index.html` reads `manifest.js` but there is no `index.html` in the repo root. Shipping a minimal one would make the site actually browsable.
4. **Per-motif formula bank** – The `--save-formula` pattern from `trace` is great; extending it to sacred and plot generators would let each design be re-parameterised without re-running the full pipeline.
