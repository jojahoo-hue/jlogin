## What Remains / Next Ideas

1. **Expand the generator library**: The scheduled task expects `metatron`, `mandala`, `harmonograph`, `spirograph`, and `forest` generators that don't yet exist. Implementing these would make future routine runs richer and closer to the intended workflow.
2. **Outline mode variants**: All sacred geometry was rendered in silhouette mode. Adding outline variants would double the stencil options for Cricut cutting.
3. **Colour/fill experiments**: Current SVGs are single-colour stencils. Exploring layered SVGs (separate layers per colour) could enable multi-colour Cricut projects.
4. **Animated preview**: Converting a selected SVG to an animated `<svg>` for the web gallery would improve presentation of complex pieces like superformula.
5. **Gallery search/filter**: The static site has 712 artefacts — adding filter by type (sacred/plot/trace) or date range would improve discoverability.
