## What Remains / Next Ideas

1. **Add missing generators**: The scheduled task consistently references generators that don't exist yet — `metatron`, `mandala`, `harmonograph`, `spirograph`, and `forest` render. Implementing even one would diversify the daily output significantly.
2. **Deduplicate daily runs**: Every run produces the same 6 files with identical parameters; the gallery grows in session count but not in visual variety. Consider rotating parameters (e.g. alternating modes, different superformula exponents, randomised streamline seeds) to make each day distinct.
3. **SVG-to-PNG preview pipeline**: The gallery's `index.html` likely needs PNG thumbnails to display SVGs in browsers that load lazily. A small `cairosvg` or `inkscape --export-png` step post-generation would improve the web view.
4. **`--save-formula` for sacred/plot**: Only `trace` supports `--save-formula` today. Extending this to `sacred` and `plot` would make every artefact re-generatable from a JSON formula, which aligns with the project's stated goal.
