## What Remains / Next Ideas

1. **New motifs:** The scheduled task calls for `metatron`, `mandala`, `harmonograph`, `spirograph`,
   and `forest` renders — none are implemented. Adding even one of these generators would
   meaningfully expand the library.
2. **Mode-aware filenames:** `generate_sri_yantra` and `generate_flower` always save to the same
   stem regardless of `--mode`. Adding the mode suffix (e.g., `sri-yantra-silhouette.svg`) would
   allow both variants to coexist in the same output directory.
3. **Trace variety:** Only the `horse` reference image is rendered for tracing. Adding a second
   reference image (e.g., a geometric or botanical shape) would give the trace pipeline a fresh
   daily input.
4. **Formula gallery:** The `horse-formula.json` file is now tracked, but the site index doesn't
   expose formula files separately. A dedicated formula browser would let Njaho re-render
   saved Fourier shapes without re-tracing.
