2. **Vary parameters across runs** — Currently each run produces near-identical files (same size, same options). Seeding `streamlines` and `superformula` with varying parameters (different `m`, `n` values, angle seeds) would make the gallery more diverse.
3. **Flower of Life variants** — The `flower` generator likely accepts a `--rings` parameter; exploring different ring counts would add variety without new code.
4. **Thumbnail generation** — PNG thumbnails of each SVG would enable a visual gallery on the static site without requiring browser SVG rendering.
5. **Deduplication check** — The routine always writes the same filenames; a diff check before commit would avoid committing identical files day after day.
